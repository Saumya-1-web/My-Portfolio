# Saumya Gupta — Personal Portfolio

A modern, responsive personal portfolio website built using **HTML and CSS**.
The portfolio showcases my academic background, professional experience, technical skills, leadership experience, and creative design skills.

## ✨ Features
* Modern dark-themed interface
* Responsive layout for desktop and mobile devices
* Fixed profile sidebar on desktop
* Smooth scrolling content area
* Profile image with animated glow effect
* Interactive hover animations
* Experience and role cards
* Technical skills displayed as interactive tags
* Responsive design for screens below 900px
* Google Fonts integration using:

  * Plus Jakarta Sans
  * Space Grotesk

## 🛠️ Technologies Used
* **HTML5** — Website structure and content
* **CSS3** — Styling, layout, animations, and responsiveness
* **Google Fonts** — Typography
* **Flexbox & CSS Grid** — Page layout
* **CSS Animations & Transitions** — Interactive effects

## 🎨 Design
The website uses a dark visual theme with:
* `#0b0f19` main background
* Blue and purple accent colors
* Glassmorphism-inspired cards
* Asymmetric two-panel layout
* Rounded profile image
* Gradient glow effects
* Animated hover interactions
The desktop layout uses a **38% fixed sidebar and 62% scrolling content area**.
